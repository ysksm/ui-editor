# 題材のプロジェクトファイル（poc-0）

#1 の題材「機器の設定＆モニタリング」をスキーマ poc-0 で書いたもの。オリジナル PoC のテストと QA の共通入力。

| ファイル                  | 内容                                                                                           |
| ------------------------- | ---------------------------------------------------------------------------------------------- |
| `device-monitor.poc.json` | ER（4 エンティティ）、入れ子のデータ、3 画面・2 ダイアログ。決定的な書き出しの形で保存している |

## 収録内容

**ER**: `Device` の下に `DeviceSettings`（1 件）・`Metric`（配列）・`Alarm`（配列）を入れ子で持つ。v0 の `DeviceSettings.network` / `thresholds` は平らにし、`Metric` / `DeviceSettings` には主キーを足した。

**データ**: v0 のサンプルデータ（`packages/schema/src/domain/sample-data.ts`）から作った。機器 5 件、設定 5 件、メトリクスは各機器の直近 3 件（15 件）、アラーム 10 件。

| id             | 種別       | 役割    | 内容                                                                        |
| -------------- | ---------- | ------- | --------------------------------------------------------------------------- |
| `dashboard`    | 画面       | —       | 未確認のアラーム（`data.Alarm` は全機器のアラームを並べた一覧）、機器一覧へ |
| `devices`      | 画面       | list    | 機器の表（選択できる）。行クリックで詳細へ、選んで「編集」で `deviceEdit`   |
| `deviceDetail` | 画面       | detail  | 機器の項目とアラームの表。「削除」で `deviceDelete`、「一覧へ戻る」         |
| `deviceEdit`   | ダイアログ | form    | 下書き（`draft`）を入力欄で編集し、保存（`saveDraft`）で反映                |
| `deviceDelete` | ダイアログ | confirm | 「削除する」で `deleteRecord`（入れ子の子も消える）→ 閉じる → 一覧へ        |

`model` のテスト（`src/examples.test.ts`）で、問題なく読み込めること、読み込み → 書き出しでテキストが変わらないこと（正規化されていること）を確認している。手で直したら、`serializeProject` で書き出し直す。
