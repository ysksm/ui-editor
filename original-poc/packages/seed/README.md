# @ui-editor/poc-seed

ER（エンティティ定義）からサンプルデータを作る（FR-ER-04）。[@faker-js/faker](https://fakerjs.dev/) の日本語ロケールを使う。

```ts
import { generateSampleData } from "@ui-editor/poc-seed";

const { data, counts, warnings } = generateSampleData(project.entities, {
  counts: { Device: 5, Alarm: 20 }, // 入れ子のエンティティは全親の合計
  seed: 1,
});
```

## 決め方

- **件数**: 指定が無ければ、ルートは 5 件、入れ子の子は親 1 件あたり 3 件、1 件だけの子（`cardinality: "one"`）は親と同じ数（`defaultCounts`）。
- **入れ子**: 親から順に作り、子を親に配る。件数が親の数以上なら、どの親にも 1 件以上。少なければ一部の親だけが持つ。
- **主キー**: `<エンティティ id の kebab-case>-001` からの連番（木の順）。
- **ref**: 全部作ってから、参照先のエンティティの実在するレコードを選ぶ。参照先が 0 件なら null（必須なら警告）。
- **値**:

| 型        | 値                                                                                                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `string`  | 書式（email / url / phone / ipv4 / multiline）、無ければフィールド名から（名前 → 「機器 1」、人のエンティティなら氏名、型番 → `KS-101`、バージョン → `1.3.3`、内容・メモ → 文、会社・住所） |
| `number`  | `min`〜`max`（無ければ 0〜100）。回数・秒・間隔などの名前なら整数、それ以外は小数 1 桁                                                                                                      |
| `date`    | 基準日時の 30 日前まで（秒は 0）。`format: "date"` なら日付だけ                                                                                                                             |
| `enum`    | 値からランダム                                                                                                                                                                              |
| `boolean` | ランダム                                                                                                                                                                                    |

- **決定性**: 同じシード・同じ基準日時（`refDate`、既定 2026-10-01T00:00:00Z）・同じ ER なら同じデータになる。生成した日に左右されない。
